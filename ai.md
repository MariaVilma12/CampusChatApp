# AI Usage Report

## 1. Which AI tools did I use?

During the development of this project, I used the following AI tools:

- ChatGPT (OpenAI)
- Claude (Anthropic)

These tools were used to assist with understanding concepts, generating example code, explaining Blazor features, and improving documentation.

---

## 2. How did I use the AI tools?

The AI tools were used as learning and development assistants throughout the project.

Examples of how they were used include:

- Explaining the assignment requirements.
- Generating example C# model classes.
- Creating sample seed data and service classes.
- Explaining Blazor concepts such as Dependency Injection and Protected Session Storage.
- Suggesting project structure and folder organization.
- Assisting with writing project documentation such as the README, design document, and this AI report.
- Helping troubleshoot compilation errors and application issues.

All generated code was reviewed, tested, and modified where necessary before being included in the final project.

---

## 3. What worked well?

Using AI significantly improved development speed and understanding of Blazor concepts.

The AI tools were especially helpful for:

- Understanding unfamiliar ASP.NET Core Blazor features.
- Generating boilerplate code.
- Explaining error messages.
- Suggesting cleaner project organization.
- Improving documentation quality.

The explanations also helped me understand why certain solutions were chosen instead of simply copying code.

---

## 4. What did not work well?

Although AI was very helpful, it occasionally generated code that required changes before it could be used.

Examples included:

- Code that did not exactly match my project structure.
- Suggestions using different .NET versions.
- Minor syntax or namespace issues.
- UI examples that needed adjustment to fit the assignment requirements.

Because of this, every AI-generated suggestion was reviewed, tested, and adapted before being used in the project.

---

## Reflection

AI was used as a learning and productivity tool rather than a replacement for my own work. It helped me better understand Blazor development, organize the project, and solve implementation problems more efficiently. The final application reflects my own testing, debugging, and integration of the generated suggestions.
